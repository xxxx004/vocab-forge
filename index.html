Bu Siteyi Canlıya Alma (0 TL / Sınırsız)

Bu uygulama tamamen tek parça saf web kodundan oluşur. Dünyanın her yerinden girebileceğin gerçek bir web sitesine dönüştürmek için 2 dakikalık şu yollardan birini seçebilirsin:

1. Yol: Netlify Drop (En Kolayı - Kod Yazmadan)
  1. Bu index.html dosyasını bilgisayarına indir.
  2. app.netlify.com/drop adresine gir.
  3. Dosyayı içeren klasörü sürükleyip o sayfaya bırak.
  4. 3 saniye içinde sana senin-adin.netlify.app şeklinde ömür boyu ücretsiz canlı bir web sitesi verir!
2. Yol: GitHub Pages (Kalıcı & Kendi Domaininle)
  1. GitHub hesabında vocab-forge adında yeni bir repo aç.
  2. Bu index.html dosyasını yükle.
  3. Settings > Pages bölümünden "Deploy from a branch (main)" seç.
  4. Siten kullaniciadin.github.io/vocab-forge adresinde anında yayına girer. İstersen .com domainini de tek tıkla bağlayabilirsin.

Yedekle / Cihazlar Arası Aktar
